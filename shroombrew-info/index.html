The Wii Shop Channel,
back online.

Shroombrew is a fan-made revival of the Wii Shop Channel. The patched channel talks to its own server instead of Nintendo's, so a real Wii can browse the catalog and install titles again. It has official WiiWare and Virtual Console games, homebrew and Flash games, and the points are free.

01Points

Wii Points you make yourself

On the website you press a button and get a card code. Cards are worth 1000 to 5000 Wii Points each and work once. On the Wii you choose Add Wii Points and type the code in. A new card takes 15 seconds, and each address can only hold a few unused ones, so nobody can flood it.

02Your console

One code ties a Wii to the site

The shop asks the Wii who it is once per launch and keeps only a keyed hash of its identifiers. Settings on the Wii gives a code that works once. Typing it into the website lets the site show your points history, friends and gifts.

03Installing

Straight from the shop

Install the patched WAD once, then browse the catalog on the Wii and install titles from the shop. It talks to Shroombrew's server instead of Nintendo's, so official WiiWare and Virtual Console titles, homebrew and Flash games all sit in one place.

04Credits

Whose work this is built on

The shop's look comes from wiishopchannel.net by Nathan, used with permission. The homebrew catalog comes from the Open Shop Channel. The server started from WiiSOAP. Shroombrew is free, and if anyone charged you for it you were scammed.
