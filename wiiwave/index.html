Nintendo WFC,
back online.

WiiWave is a community revival for Nintendo WFC. It rewrites a disc image so the game talks to its own server instead of Nintendo's. Wii Chess is supported, Super Smash Bros. Brawl's patch is in testing, and Mario Kart Wii is next.
