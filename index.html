01Wii

Shroombrew

Shroombrew is a fan-made revival of the Wii Shop Channel. The patched channel talks to Shroombrew's own server instead of Nintendo's, so a real Wii can browse the catalog and install titles again. The catalog has official WiiWare and Virtual Console games, homebrew and Flash games. Wii Points cards are made on the site, and there are community pages for friend codes, gifts and points history.

Built with
Go, PostgreSQL, a C forwarder for devkitPPC
Status
Live. Built for the original Wii; vWii on Wii U is untested.

02Mario Kart Wii

WiiWave

A community server for Mario Kart Wii's Nintendo WFC. It runs ranked races, a weekly league, seasons and rotating events, and its page shows the standings.

03tiptoi

RAVage

Converts mp3, wav, m4a or flac into the .rav files a Ravensburger tiptoi pen plays, and decrypts stock ones back to ogg. The converter runs in the browser, so nothing is uploaded. There are desktop builds too.

Built with
Python, JavaScript, WebAssembly
Tested on
A 3203L pen
